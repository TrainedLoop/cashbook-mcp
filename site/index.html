Beta v0.1.1, open source under MIT

Ask your assistant about your money. It can only read it.

An MCP server you run yourself. It syncs your bank accounts, cards, investments and loans from Pluggy (through the free MeuPluggy connector, Brazilian Open Finance) into an encrypted database on your own disk, and lets Claude answer questions about spending, bills and recurring charges.

Set it up GitHub

  • Read-only, end to end

    The server never changes anything at Pluggy, and every tool only reads. The SQL tool accepts a single SELECT in a locked-down sandbox.

  • Your data, your disk

    One DuckDB file, encrypted, with the key kept outside the data volume. History keeps growing past what Pluggy provides.

  • Safe against hostile text

    Anyone can send you a PIX with a message. Transaction text is cleaned, capped and flagged, and the assistant is told it is data.

What the assistant can do

ToolPurpose
finance_overviewBalances, cards, upcoming bills, month to date, top categories, connection problems
search_transactions, get_transactionsFiltered, paginated search; full rows by id
summarize_transactions, cash_flow, find_recurringAggregations and recurring-charge candidates
list_bills, list_investments, list_loansCards, investments and loans
describe_schema, query_sqlThe schema, and SELECT-only SQL over it

One owner per instance: only Google logins in ALLOWED_EMAILS get in. An owner page at /admin connects banks with MeuPluggy and works on a phone.
